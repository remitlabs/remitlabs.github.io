least privilege for agent skills

Every AI-agent skill declares what it may do, proves it in a sandbox before install, and dies everywhere within a day if it turns bad.

static — ≈20 high-signal rules canary — every skill runs boxed revoke — signed feed, daily sync

the state of skills today

Today a skill vouches for itself: a description in prose, some stars, maybe a README skim. Nothing runs it in a box before your agent loads it. Nothing watches what it does after. And nothing revokes it when a maintainer turns hostile at 2am — so install a stranger's skill and pray. The same "summarize notes" skill can ship "curl … | sh" or quietly read ~/.ssh: our detection corpus keeps specimens of exactly that, and they fool a human skim.

how existing skills are handled

your current fleet

Point skillctl audit at the skill dirs your agents already use — Claude Code, Codex, Cursor and friends. Every skill gets findings plus a canary diff, not a hunch. Measured on one real machine: 123 skills across 4 agent dirs, 114 duplicate registrations found and collapsed.

new installs

Marketplace search (skills.sh + GitHub) funnels installs through one gate: clone → scan → policy → digest — before files ever land. Gating is being extended to every install path, honestly tracked in the repo.

updates & rug-pulls

A lockfile pins every skill's sha256. If a maintainer re-publishes a skill you installed, update time runs a semantic diff — changed behavior is flagged, never silently adopted.

running & revocation

The MCP router loads skills on demand — ~150 tokens vs 15,238 of eager context on one real machine. hook-guard watches live sessions against network allow-lists, and the Ed25519 feed syncs daily: revoked skills are killed; hand-installed copies get parked with a removal note, never silently touched.

why this is different

neutral measurement layer

Not a marketplace with inventory to protect. Not an agent selling you its own skills. Remit is the evidence layer on top of whatever supply chain your agent already uses.

verdicts with receipts

Every verdict ships as an evidence scorecard: the rule hits, the canary diff, the pinned sha256, the signature. You can re-run the proof yourself — trust is verifiable, not vibes.

revocation with a deadline

Security without a kill switch is theater. The signed feed gives every install a clock: dead everywhere within a day, herd-wide.

local-first, runs anywhere

Index, scanner and sandbox detonations run on your machine; the fleet API self-hosts or embeds. No cloud round-trip needed for a trust decision — and works offline.
