A skill is a document, a program, and a permission slip.

The frontmatter is what you review. The body is what your model obeys. The scripts beside it run with your keys. All three arrive in one folder you copied from a link.

05lifecycle

What happens after you run it.

audit

Point skillctl audit at the skill dirs your agents already use. Every skill gets static findings; when Docker or Podman is available, a canary diff too. 123 skills, 4 agent dirs, 114 duplicate registrations on the machine this was built on.

wire

skillctl setup merges each agent’s MCP config and the Claude Code hook, never replaces them, and writes a timestamped backup before the first change. Safe to run twice. The hook stays observe-only until you set REMIT_ENFORCE=1.

install

Marketplace search (skills.sh and GitHub) funnels installs through one gate: clone, scan, policy, digest, before files ever land. CLI and marketplace installs share the same decision.

update

A lockfile pins every skill’s sha256. If a maintainer re-publishes a skill you installed, update time runs a semantic diff. Changed behaviour is flagged, never silently adopted.

revoke

The MCP router loads skills on demand (~150 tokens vs 15,238 of eager context). hook-guard watches live sessions against network allow-lists, and the Ed25519 feed syncs daily: revoked digests are blocked by the router and the feed. Remit-home copies are removed; hand-installed files get parked with a removal note, never silently touched.

06position

Why a scanner is not this.

neutral

Nobody here is selling the skills

Not a marketplace with inventory to protect, not an agent grading its own homework. Remit is the evidence layer under whatever supply chain your agent already uses.

receipts

Every verdict arrives with its workings

The rules that fired, the canary diff when it ran, the pinned digest, the feed status. You can reproduce the proof instead of taking a score on faith.

deadline

A clock on every install

Security without a kill switch is theatre. The signed feed gives every skill a deadline: a revoked digest is blocked at load, herd-wide, on the next daily sync.

local

The decision runs on your laptop

Index, scanner and sandbox detonations are local. The fleet API self-hosts or embeds. No cloud round-trip is needed to trust a skill, and the core works offline.

08limits

What this does not prove.

A finding is a rule match, not proof of intent. A canary receipt is one observed run in a container, not a guarantee that a skill is safe. Static coverage can be partial; compiled or encrypted files are blind spots. The canary is observer-first by default and enforces egress only when you pass an allowlist. Remit is defence in depth, not a clean bill of health.
