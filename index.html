Remit

least privilege for agent skills

Every AI-agent skill declares what it may do, proves it in a sandbox before install, and dies everywhere within a day if it turns bad.

  "proof": "static scan clean · canary 0 outbound · sha 9f8e…"
}

01 · declare

Each skill ships a remit — the narrow scope it may act in. No remit, no trust: the description alone is marketing.

02 · prove

Before it loads, the skill detonates in a disposable canary sandbox. You see observed behavior against the declared scope — static findings plus runtime diff — before install.

03 · die

A signed revocation feed with daily sync means a skill that turns bad is dead on every machine within a day.
