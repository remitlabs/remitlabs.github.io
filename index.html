What should I know before running it?

The file scan runs locally and leaves your skill files unchanged. It works offline once Remit is installed, on macOS, Linux and Windows.

Optional container tests need Docker or Podman and run without your AI agent or model. Network blocking requires an explicit allowlist. File scans can miss compiled or encrypted code, and a test records only one run.

Remit's router blocks listed versions after syncing the signed revocation list. Shared team features are in development.
