How Remit fits your workflow

Package scanners

If you use tools such as Socket or Snyk, check whether your setup also reviews agent skill instructions and later updates. Run a local Remit scan to compare the findings for your skills.

Skill registries

Registries help you find skills. Before loading one, review its instructions, scripts and requested access. Remit records findings and identifies the exact version checked.

Platform signing

Check what a vendor's signature verifies and which agents it covers. Remit applies a skill policy across its supported coding agents.

Manual review

Read the instructions and code that matter to your setup. Remit helps locate risk patterns, records findings and highlights version changes for another review.

Read the limits with the findings.

File checks can miss harmful behavior. A container test records one run. Remit's router can check only the skills loaded through it. The local CLI is available in public beta, and shared team features are in development.
