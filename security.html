The evidence chain,
and where it stops.

Remit is not a scanner with a badge. It is a chain: source → digest → findings → observed behavior → policy → install → update diff → revoke. Each link states what it saw and what it could not see.

The chain

source

Where it came from

Registry, repo, or local author. Recorded, not trusted. A source is a claim; the digest is the fact.

digest

The exact bytes

A clean verdict is bound to a content hash, not to a name. A clean yesterday cannot be inherited by a changed skill today.

static

64 rules

Rule matches over SKILL.md and scripts: secret paths, curl-pipe-shell, reverse shells, hidden unicode, encoded instructions. Not proof of intent.

canary

One observed run

A disposable container with fake secrets, strace, and a logging proxy. Records credential touches, egress, file writes, and shell commands. Observer-first.

policy

Allow, monitor, review, deny

Each decision carries its reason and its missing coverage. Review-level loads refuse unless you opt in.

revoke

A signed kill switch

An Ed25519-signed feed. A revoked digest is blocked at MCP load and on the next sync; hand-installed copies are surfaced.

Threat model

prompt injection

A SKILL.md that turns the agent into a credential thief without a single malicious script. The model reads the text as direction.

install ritual

"Run this first" instructions that ship a stealer. ClawHavoc installed Atomic Stealer on macOS this way.

rug pull

A clean skill that turns malicious after install. The lockfile and semantic update diff catch changed bytes.

hidden payloads

Hidden unicode, base64 blobs, encoded instructions, oversized or compiled files that a human skim will not read.

over-broad scope

File and network access that exceeds the declared remit. Declared vs observed is the diff that matters.

fleet drift

Duplicate, stale, or revoked copies across four agent directories, and no way to reach 40 laptops.

What each layer cannot see

LayerCannot see
Static scanIntent; compiled, encrypted, or oversized files; behavior at runtime.
CanaryOther hosts; TLS bodies; the model's reasoning; a conditional trigger that did not fire.
Digest / lockfileWhether the original author was honest — only whether the bytes changed.
Revocation feedSkills that never sync; hand-installed copies (surfaced, not silently removed).
MCP routerTool calls outside the router; a compromised host.
hook-guardCommands outside the hook; enforcement is opt-in (REMIT_ENFORCE=1).

A clean scan is not proof that a skill is benign. The product says so on every receipt.

Data handling

Local scan

Runs on your machine. No upload. The index, scanner, and container detonation are local.

Local dashboard

Binds to 127.0.0.1:8787. Nothing is exposed to the network by default.

Self-hosted API

Runs on your infrastructure (Postgres, PGlite, or SQLite). The evidence stays yours.

Hosted team tier

Not yet shipped. Before GA we will publish a data-flow diagram, subprocessor list, retention policy, and DPA.

Telemetry

Opt-in only. Aggregate activation events. No skill content, no file paths, no code.

Deletion

Export everything as JSON/markdown for 30 days after cancellation, then delete on request.

Report a vulnerability

Please do not open a public issue for a security problem. Email singhgaurprahalad@gmail.com with [security] in the subject and include the package version, a minimal reproduction, and the impact. We aim to acknowledge within 72 hours.

Machine-readable contact: /.well-known/security.txt. There is no bug bounty yet; we will credit reporters who want it.

Status

Public beta. The local tool is stable enough to use daily; the team control plane is in design-partner development. We label features as they ship rather than implying they exist.
